# UI Style Specification

## Core Direction

The primary visual direction is a minimalistic liquid glass interface. This is the most important design principle and should guide the entire experience.

## Overall Appearance

- Use slightly opaque liquid-glass surfaces throughout the interface.
- Keep the visual language clean, restrained, and spacious.
- Use translucency, soft layering, and subtle depth without adding unnecessary decoration.

## Conversation Layout

- Place a sidebar on the left side of the interface.
- The sidebar should display the five most recent conversations.
- The sidebar should occupy a meaningful portion of the layout while remaining visually lightweight and integrated with the liquid-glass treatment.

## Chat Composer

- The chat input should follow a familiar, standard chat-interface layout.
- Place a plus (+) control on the left for adding attachments.
- Place the model selector on the right.
- Keep the composer simple, compact, and consistent with the minimalistic liquid-glass aesthetic.

## Minimized State

When minimized, the interface should show only the chat box. It should appear as a small rectangular element with no sidebar or additional controls visible beyond what is necessary for the compact chat experience.
